# Expected artifacts

This directory contains only deterministic expected metadata until conversion and GLB packaging tasks are implemented. Later tasks may add canonical manifest or artifact checksums only when generated from the self-authored fixtures under a reproducible procedure.

Expected files must use normalized forward-slash paths, stable key ordering, LF line endings, and SHA-256 checksums. Generated GLB/texture binaries do not belong here until the corresponding converter task proves they can be regenerated byte-for-byte or documents the exact permitted serialization variance.
